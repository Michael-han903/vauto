## 3. 从时间线推出的设计约束

1. **A 是"长睡 + 两个小判定"**：一轮约 542 秒。不需要轮询式全帧搜索；
   睡到 ~(T_round − 缓冲) 再开始查结算判据即可（ROI 匹配 7 ms/次）。
2. **结算判据用 `hint_esc_retry`（0.991，余量 0.11）比 `panel_result`（0.641，余量 0.11）更稳**，
   两个都用、并要求其中一路连续 2 帧命中。
3. **"这台车做完了" = `hint_unlock_all` 从命中变为不命中**（0.996 → 0）。
   解锁前后点数变化可作二次确认。
4. **`车辆熟练度` 入口打开的是"当前车辆"的精通页** → B 会改掉当前车辆；
   而 A 必须用 22B，所以 **B 收尾必须切回 22B**（或每轮 A 之前校验）。
5. **进挑战的 5 步菜单只在首次需要**；后续每轮一个 Esc。
6. **`hint_esc_back` 不能当作页面判据**：它匹配的是提示条前两格（`Enter 选择 | Esc 返回`），
   主菜单/车库/精通页都会命中 0.97+。页面识别必须用 `page_title_*`。
7. **官方/第三方性能悬浮窗**（右上角「142 显卡: 76%」）全程存在；现有 ROI 都不在那块，不受影响。
