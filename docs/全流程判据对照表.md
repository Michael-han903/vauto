### 1.4 到精通页 → 解锁判定（核心）

| 步骤 | 动作 | 符合判据 | 不符合 |
|---|---|---|---|
| 点「车辆熟练度」 | 模板 `tile_mastery` | ≥ 0.62 | 点不到 → `no_page` |
| 等精通页 | `page_title_mastery` | ≥ 0.70 | 超时 → `no_page` |
| **判"有没有可解锁"** | **底部「Y 解锁全部」提示 `hint_unlock_all`** | **≥ 0.805 = 还有可解锁的**（实测你截图 0.996） | 两窗都看不到 → 判 `already`（本页已解锁过） |
| 上一条的等待 | 两个独立窗口：各 `hint_wait`（默认 **6s**），中间隔 2.5s | 任一窗看到 → 继续解锁 | 两窗都看不到 → 才认 `already`（防止"还没渲染出来"被当已解锁 ✗） |
| 执行解锁 | 按 `Y`（解锁全部）→ `Enter`（确认） | 等过渡 ≥1.6s 后，**连续 3 帧**看不到提示 = 解锁成功 ✓ | 提示还在 → 见下 |
| 解锁中弹「不够支付全部」 | `popup_no_resource`（先看**原始分** ≥0.626，再去抖） | 命中 = `no_points`（不急收藏、清记忆、回 22B 去刷） | — |

## 3. 主循环（循环往复）

```
默认（先花后刷）：
   B：一路解锁到「技能点不足」  ← 这本身就是"点数够不够点满一台车"的检查
       ├─ 遇到不足 → 切 22B → A 跑 N 轮 → 回车库接着花 → …
       └─ 没遇到不足（车库没车可花了）→ 收工
farm_first=True（可选）：开局直接先刷 N 轮，再去车库花，花完再刷，循环往复
cycles<=0 = 一直循环（默认，靠 F1 停）；cycles=N = 只跑 N 圈
```

| 安全闸 | 判据 | 行为 |
|---|---|---|
| F1 | 物理键盘监听 | 释放所有按键 + 中止 |
| 前台守卫 | 目标窗口是否前台 | 暂停等待（切回来继续） |
| dry-run（默认） | `dry_run=True` | 只判不按 |
| 全黑兜底 | 纯黑持续 > 3s | 打印提示 + 等恢复（≤300s，F1 可打断） |
| 总时长 | `max_runtime_min`（0=不限） | 到点停 A 阶段 |
| 画面验货 | 尺寸/亮度 | 不符 → 拒绝动作 |
