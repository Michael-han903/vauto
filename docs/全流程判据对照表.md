## 3. 主循环（循环往复）

```
默认（先花后刷）：
   B：一路解锁到「技能点不足」  ← 这本身就是"点数够不够点满一台车"的检查
       ├─ 遇到不足 → 切 22B → A 跑 N 轮 → 回车库接着花 → …
       └─ 没遇到不足（车库没车可花了）→ 收工
farm_first=True（可选）：开局直接先刷 N 轮，再去车库花，花完再刷，循环往复
cycles<=0 = 一直循环（默认，靠 F1 停）；cycles=N = 只跑 N 圈
```

| 安全闸 | 判据 | 行为 |
|---|---|---|
| F1 | 物理键盘监听 | 释放所有按键 + 中止 |
| 前台守卫 | 目标窗口是否前台 | 暂停等待（切回来继续） |
| dry-run（默认） | `dry_run=True` | 只判不按 |
| 全黑兜底 | 纯黑持续 > 3s | 打印提示 + 等恢复（≤300s，F1 可打断） |
| 总时长 | `max_runtime_min`（0=不限） | 到点停 A 阶段 |
| 画面验货 | 尺寸/亮度 | 不符 → 拒绝动作 |

## 一、判据层（是真的判据变更）

| 判据 | 变更 | 依据 |
|---|---|---|

## 五、自愈层（新能力）

`recover_to_known()`：卡在"认不出的界面"时，按当前状态标签选动作并每按一次重新判：

| 状态 | 动作 |
|---|---|
| `dialog_home`（移动至住所） | ↓ 选「取消」+ 回车（**Esc 关不掉它**，实测） |
| `dialog_nopts`（不够支付全部） | 回车关掉 |
| `dialog_rate`（为挑战评分?） | `dialog_cancel_key`（默认回车，按用户口径） |
| `car_menu`（选择操作菜单） | Esc |
| 其余认不出的 | Esc（退一层） |

铁律：**认不出的时候绝不按回车**（历史上误触「移动至住所」「查看车辆」都是回车导致的）。
开关：`auto_recover`（默认开）、`recover_rounds`（默认 4）。

## 六、提速（翻列表）

| 项 | 10-03 | 10-04 | 实测 |
|---|---|---|---|
| 翻一屏抓几帧 | **2 帧**（按之前 + 按之后） | **1 帧**（按完不抓，下一轮用已抓到的帧结算 diff） | 3840×2160 抓一帧 ≈ **84 ms**（本机实测） |
| 车格区 HSV | 每步 `_grid_tiles` 与 `_cursor_box` 各做一次**全帧** BGR2HSV | 同帧只算一次，且只算 `grid_area`（≈ 全帧 55%） | 每步 62.5 ms → **31.6 ms**（-49%） |
| "绕回开头"判据 | 跟"所有看过的屏"逐一比缩略签名 | 只跟**本轮第一屏**比（`attempt>=3` 才认） | 语义正是"翻完一圈回到开头"，且不会被别处相似缩略图误判成"翻完了" |
| 翻列等待 | 固定 `grid_walk_dwell`(0.45) | 独立 `grid_scroll_dwell`（默认仍 0.45 = 不变；**调小即提速**，用 `grid_advance` 的 diff 验证是否滚到位） | 每屏 ≈0.6 秒的等待是这条链路最大的一块时间 |
