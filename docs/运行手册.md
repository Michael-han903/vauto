| 环节 | 状态 |
|---|---|

| B 阶段：换车 → 精通页 → Y + Enter → 点数不足收尾 | ✅ 已实现；**首次在线要复核**（两个判据是手工推定阈值） |

| **首次进入赛事那 5 步菜单** | ❌ 未实现 —— 仍是人工：主菜单 → 创意中心 → EventLab → 搜索 → 共享代码 161047605 |
| 解锁完 B 之后**自动切回 22B** | ❌ 未实现（需要品牌标签栏/搜索素材），目前靠人工 |

结论：**你在游戏里把赛事开起来（或停在结算重试循环里），程序可以接手全自动跑 A↔B。**
第一次请按下面 1→2→3 顺序来。

## 1. 先只看不按（dry-run）

```bash
py -3.14 run_vauto.py --list                        # 找窗口标题关键字
py -3.14 run_vauto.py --title "Forza Horizon 6" --phase farm --rounds 1
```
默认就是 dry-run：**一个键都不按**，只打印"本应按什么 + 判据分数"。
把游戏切到"挑战进行中"，你会看到它报 `本应按住 'w'`；把画面弄到结算，
它会在 2 帧后报 `结算判据命中（0.99x）`，然后 `本应按下 'esc'`。
这一步先确认：**它认得出结算画面、且不会在别的时候误判**。

## 2. 单轮真实按键（你在旁边）

```bash
py -3.14 run_vauto.py --title "Forza Horizon 6" --phase farm --rounds 1 --live
```
只会：按住 W → 等结算 → 松手 → 按一次 Esc。约 9 分钟。**手放在 F1 上。**
跑完检查游戏里挑战是否重开了。

## 3. 放开跑

```bash
py -3.14 run_vauto.py --title "Forza Horizon 6" --phase farm --rounds 4 --live
py -3.14 run_vauto.py --title "Forza Horizon 6" --phase spend --cars 6 --live
```
- `--phase farm --rounds 4`：连跑 4 轮（最后一轮结束按 Enter 离开赛事）
- `--phase spend --cars 6`：从「车辆」→「更换车辆」往下走 6 台车，逐台解锁；
  一旦弹出「不够支付全部」就停下并提示回 A 刷点
- `--phase both`：先 farm 再 spend（**注意**：spend 会把当前车辆换成别的车，
  再跑 farm 之前必须手动把车换回 1998 斯巴鲁 Impreza 22B-STI）

## 4. 按键与动作对照表

| 键 / 操作 | 什么时候 | 干什么 |
|---|---|---|
| W（按住不放） | 赛事加载完 → 结算出现 | 挑战进行中的唯一输入 |
| Esc | 结算画面 / 从子页面返回 | 重试（重开赛事）/ 返回上一级 |
| Enter | 结算画面 / 选择操作菜单 / 精通页确认框 / 弹窗 | 继续（离开赛事）/ 选「上车」/ 确认解锁 / 关弹窗 |
| Y | 精通页且提示条有 `[Y] 解锁全部` | 一键解锁本页全部额外加成 |
| 鼠标左键 | 主菜单：「车辆」标签、「更换车辆」磁贴、「车辆熟练度」磁贴 | 导航（会走贝塞尔轨迹 + 落点抖动） |
| 方向键 | 「更换车辆」列表 | 选车（每步都用像素变化验证，见 `flow/nav.py`） |
| F1（只监听） | 任何时候你手按 | 全局急停：停手 + 释放所有按下的键 |

## 5. 出事怎么办

- **按 F1**：立刻中止，并松开包括那只一直按着的 W。
- **Ctrl+C**：终端里也能中断。
- 目标窗口切到后台：所有动作自动暂停（不会盲按），切回来继续。
- 日志在 `logs/run_*.jsonl`，每一条动作/判据都在里面；台账在 `logs/ledger.json`。
- 想复盘"上一轮为什么停"：看日志最后的 `settle / retry_ack / car_ok / no_points` 事件。

## 6. 常用参数

| 参数 | 默认 | 说明 |
|---|---|---|
| `--live` | 关 | 不加就是 dry-run（只判不按） |
| `--phase` | both | farm / spend / both |
| `--rounds` | 4 | farm 阶段几轮 |
| `--cars` | 6 | spend 阶段最多几台车 |
| `--hotkey` | f1 | 急停键 |
| `--no-car-check` | 关 | 跳过"当前车是 22B"校验 |
| `--save-config x.json` | — | 把当前配置写出来改（`--config x.json` 读回） |
| `--selftest` | — | 离线自检（不碰屏幕与键鼠） |

## 7. 已知边界（别指望它做这些）

1. **不会自己进赛事**：那 5 步菜单还没实现（需要你的点击序列）。
2. **不会自己切回 22B**：B 阶段之后需要人工换车，再跑 farm。
3. 两个手工阈值（`选择操作` 标题条、「上车」行）是**推定值**，第一次在线必须复核。
4. 走格子覆盖率约 38%（见 `docs/业务实测要点.md` 第 4 节）——重访已解锁的车是无消耗空转。
5. 游戏分辨率/DPI/窗口大小必须和素材一致（当前客户区 3840×2160）；改了就重新标定。
